# איתור גוש וחלקה על גבי תצ״א

דף אינטרנט סטטי (`index.html`) לאיתור גוש וחלקה וסימונם על גבי תצלום אוויר.

## שימוש
- פתחו את `index.html` בדפדפן (או פרסמו דרך GitHub Pages).
- הזינו גוש (וחלקה) ולחצו "איתור" — החלקה תסומן בצהוב, שאר חלקות הגוש בקו מקווקו תכלת.
- חלקה ריקה = הצגת כל הגוש. לחיצה על המפה מזהה את הגוש/החלקה בנקודה.
- קישור ישיר: `index.html?gush=6106&helka=10`

## מקורות נתונים
- חלקות: "שכבת חלקות - המרכז למיפוי ישראל" (שירות ArcGIS ציבורי, עד 2000 חלקות לבקשה; גושים גדולים נטענים בעמודים).
- תצ״א: Esri World Imagery. מפת רקע חלופית: OpenStreetMap.
- ספריית מפות: Leaflet 1.9.4.
