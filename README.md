# איתור גוש וחלקה על גבי תצ״א

דף אינטרנט סטטי (`index.html`) לאיתור גוש וחלקה וסימונם על גבי תצלום אוויר.

## שימוש
- פתחו את `index.html` בדפדפן (או פרסמו דרך GitHub Pages).
- הזינו גוש וחלקה ולחצו "איתור" — החלקה תסומן בצהוב, שאר חלקות הגוש בקו מקווקו תכלת.
- אפשר להזין כמה חלקות (`49,50,51`) או טווח (`49-51`). Shift + לחיצה על חלקה במפה מוסיפה/מסירה אותה.
- פרטי החלקות מוצגים בסגנון תשריט: תיבת פרטים (כולל תוכנית ומגרש למילוי ידני), מס׳ תיק (לעריכה), וטבלת גוש | חלקה | חלקיות | שטח בדונם.
- סימון שטח: כלי ציור פוליגון/מלבן. השטח המסומן בכל חלקה מחושב אוטומטית (נמדד גרפית) ומתווסף לטבלה; הסימון נשמר בקישור.
- "שליחה במייל" פותח מייל חדש עם פרטי החלקות, הטבלה וקישור למפה. "הדפסה" מפיק דף A4 לרוחב (אפשר לשמור כ-PDF ולצרף למייל).
- תשריט להדפסה בפריסה של תשריט רשמי: מסגרת אחת, פאנל פרטים מימין, מפה ראשית עם קואורדינטות רשת ישראל ומתחתיה מפות התמצאות, טבלת גוש/חלקה/חלקיות/שטח, תיאור הסימון ותיבת הערות (הזמנה ממחלקת, מטרה, מבוסס על, הוכן ע״י, מס׳ עבודה). השדות ממולאים בדף ונשמרים בקישור; שם היחידה ושם המכין נזכרים בדפדפן.
- לחיצה על סימון מאפשרת לתת לו שם (למשל 308א).
- בדף: חץ צפון, קנ״מ משוער, שתי מפות התמצאות (תצ״א קרובה ומפת רחובות אזורית), ואפשרות להוסיף לוגו (נשמר בדפדפן בלבד).
- חלקה ריקה = הצגת כל הגוש. לחיצה על המפה מזהה את הגוש/החלקה בנקודה.
- קישור ישיר: `index.html?gush=6106&helka=7-9&tik=900699624&tochnit=תמל/2053&migrash=8612`

## מקורות נתונים
- חלקות: "שכבת חלקות - המרכז למיפוי ישראל" (שירות ArcGIS ציבורי, עד 2000 חלקות לבקשה; גושים גדולים נטענים בעמודים).
- תצ״א: Esri World Imagery. מפת רקע חלופית: OpenStreetMap.
- ספריית מפות: Leaflet 1.9.4.
